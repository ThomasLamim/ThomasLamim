#### 📦 [DW Atacado — Pipeline End-to-End de Análise Comercial e Estoque](https://github.com/ThomasLamim/Projeto_RupturaEstoqueVarejista)
Projeto completo simulando o ecossistema de dados de uma distribuidora atacadista para resolver problemas reais de operação e logística:

I focus my studies and hands-on projects on turning raw data into actionable business intelligence, combining operational background in the retail and wholesale industry with modern data analysis, modeling, and visualization tools.

### 🚀 Featured Project

#### 📦 [Wholesale DW — End-to-End Sales & Inventory Analytics Pipeline](https://github.com/ThomasLamim/Projeto_RupturaEstoqueVarejista)
An end-to-end portfolio project simulating a wholesale distributor's data ecosystem to solve real-world operational and supply chain challenges:
* **Data Engineering & Cleaning (T-SQL):** Deduplication using `ROW_NUMBER()`, string normalization, inconsistent date parsing, and null freight handling.
* **Data Modeling & BI (Power BI):** Star Schema architecture (fact and dimension tables), custom calendar table, and DAX measures tracking KPIs such as *Fill Rate*, stockout revenue loss, and supplier lead-time SLAs.
* **Data Generation & Exploration (Python):** Custom scripts for dataset simulation with real-world anomalies and exploratory data analysis.
